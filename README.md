# Граф зависимостей пакетов: вариант 17

Практическая работа № 2, **этап 3: основные операции**, ветка `stage3`.
Приложение строит граф прямых и транзитивных зависимостей NuGet-пакета
алгоритмом DFS без рекурсии. Поддерживаются фильтр по подстроке, циклы
и локальный тестовый репозиторий. Используется стандартная библиотека Python;
менеджеры пакетов и сторонние библиотеки получения зависимостей не нужны.

## Запуск

Нужен Python 3.10+. Команды выполняются из корня проекта.
Для NuGet нужен доступ к HTTP(S) репозиторию; тестовый режим работает без сети.

```sh
python3 src/main.py --package jQuery.Validation --version 1.21.0 \
  --repository https://api.nuget.org/v3/index.json --output graph.svg
```

```text
jQuery.Validation@1.21.0: jQuery@1.4.4
jQuery@1.4.4:
```

Вывод — список смежности: `пакет: зависимости`, для NuGet — `имя@версия`.
Листовая вершина выводится с пустым списком. Строки идут в порядке открытия
вершин DFS, рёбра — в порядке описания. Вывод начинается после построения
всего графа. Порядок загрузки (этап 4), PlantUML и SVG (этап 5) не реализованы.

## Параметры

| Опция | Назначение |
| --- | --- |
| `--package` | Обязательное имя исходного пакета. |
| `--repository` | Обязательный URL индекса NuGet V3 или путь к тестовому файлу. |
| `--version` | Обязательная версия: 1–4 числовых компонента, возможны суффиксы. |
| `--output` | Обязательный путь `.svg` в доступном для записи каталоге; файл не изменяется. |
| `--filter` | Подстрока в именах исключаемых пакетов, по умолчанию пустая. |
| `--test-mode` | Читать локальный тестовый файл вместо NuGet. |

Сохранена проверка параметров этапа 1: запрещены управляющие символы,
неверные URL, неизвестные и сокращённые опции, фильтр только из пробелов.
Проверяются читаемость тестового файла и путь SVG без создания файла.
Относительные пути отсчитываются от текущего каталога; поддерживается `~`.
Флаг `--test-mode` не принимает значений. Справка: `python3 src/main.py --help`.

## Построение графа

DFS использует явный стек пар «вершина, итератор зависимостей».
Новая вершина отмечается посещённой и помещается в стек сразу при обнаружении;
после исчерпания зависимостей её итератор удаляется. Рекурсия не используется.
Циклы и самопетли сохраняются как рёбра, повторный обход вершины не выполняется.
Рёбра к общим зависимостям сохраняются, одинаковые рёбра объединяются.
Несвязанные с исходным пакетом компоненты не обходятся.

Фильтр — обычная подстрока **с учётом регистра**, без шаблонов.
Пустой фильтр ничего не исключает. Проверка выполняется до выбора версии
и запроса исключаемого пакета. Его ветвь не обходится; потомок остаётся
в графе, если достижим другим путём. Исключение исходного пакета даёт
пустой граф и в режиме NuGet не вызывает сетевых запросов.

Для NuGet адрес `PackageBaseAddress/3.0.0` находится в индексе репозитория.
Загружается `.nuspec` точно указанной версии исходного пакета. Для каждой
разрешённой зависимости запрашивается список доступных версий и выбирается
минимальная подходящая версия по ограничению `.nuspec`.
Поддержаны минимум `1.0`, точная версия `[1.0]`, интервалы `[1.0,2.0)`
и открытые границы `[1.0,)`, `(,2.0]`. Без ограничения выбирается минимальная
стабильная версия; prerelease допускается, если он указан в границе диапазона.
Числовые части версии и prerelease сравниваются как числа.

Версии нормализуются: удаляются начальные нули, метаданные после `+`
и четвёртый нулевой компонент, недостающие компоненты дополняются до трёх,
prerelease переводится в нижний регистр. Например, `01.2.003.0+build` → `1.2.3`.
Вершина определяется именем без учёта регистра и конкретной версией;
для вывода сохраняется первое написание имени. Разные версии — разные вершины.
Все группы платформ объединяются; ограничения разрешаются для каждого ребра
отдельно, без глобального согласования версий для установки.

Индекс сервиса и список версий каждого имени кешируются. Каждый манифест
читается один раз на вершину. Одинаковые ограничения разрешаются один раз.
XML поддерживает пространство имён на `package` или только на `metadata`.

## Тестовый репозиторий и примеры

Файл UTF-8, в том числе с BOM, содержит строки вида:

```text
A: B C
B: C
C:
```

Имена состоят из букв `A-Z`. Каждый пакет, включая листовой, описывается
ровно один раз; порядок объявлений произвольный. Пустые строки и пробелы
вокруг `:` разрешены, повторяющиеся рёбра объединяются. Комментарии, версии,
цифры и строчные буквы не поддерживаются. Проверяется весь файл, включая
недостижимые компоненты. Пустой файл и отсутствие исходного пакета — ошибки.
`--version` проверяется, но в тестовом формате не используется.

```sh
make run ARGS="--package A --version 1.0.0 --test-mode \
--repository examples/diamond.txt --output graph.svg"
```

```text
A: B C
B: D
D:
C: D
```

Общий потомок `D` посещается один раз, ребро `C → D` сохраняется.
Несвязная компонента `X → Y` не выводится.

```sh
python3 src/main.py --package A --version 1.0.0 --test-mode --filter B \
  --repository examples/diamond.txt --output graph.svg
```

```text
A: C
C: D
D:
```

`B` исключён; `D` достижим через `C`. Фильтр `A` даёт сообщение
`Граф пуст: исходный пакет исключён фильтром.`
Другие случаи запускаются той же командой без `--filter`, с заменой файла:

| Файл | Результат |
| --- | --- |
| `examples/repository.txt` | Транзитивность: `A: B C`, `B: C`, `C:`. |
| `examples/cycle.txt` | Цикл: `A: B`, `B: C`, `C: A`. |
| `examples/self_loop.txt` | Самопетля: `A: A`. |

С `--package C --repository examples/repository.txt` выводится лист `C:`.

## Ошибки и тесты

Успешный запуск и `--help` возвращают `0`, ошибка — `2` с сообщением
в `stderr`, без частичного графа в `stdout`. Обрабатываются ошибки параметров,
чтения и кодировки файла, формата графа, HTTP, соединения, JSON и XML,
отсутствие пакета/версии, некорректные диапазоны и списки версий.
Тайм-аут сетевой операции — 20 секунд. Проверка TLS включена;
при ошибках сертификатов настройте хранилище Python или `SSL_CERT_FILE`.

```sh
make build  # Проверка компиляции
make test   # Все тесты
```

Без `make`:

```sh
python3 -m compileall -q src
python3 -m unittest discover -s tests -v
```

Тесты проверяют параметры, NuGet, диапазоны, циклы, фильтрацию,
общие зависимости, разные версии, кеширование, ошибки и сохранность SVG.
Цепочка из 1500 вершин проверяет отсутствие рекурсии.
Используется локальный WSGI HTTP-сервер из стандартной библиотеки;
внешняя сеть не нужна, окружение должно разрешать локальные сокеты.
Служебные файлы и результаты сборки исключены через `.gitignore`.
